LOCAL CONNECTION / 仅限本机

登录照常，
同步只需一次点击。

用日常 Edge 完成美团登录，再通过扩展导入登录状态。不接管浏览器，不上传 Cookie。

01 / 首次连接

配对你的浏览器

在 Edge 的扩展管理页打开“开发人员模式”，选择“加载解压缩的扩展”，加载项目中的 extensions/meituan-login-sync 文件夹。

点击下方按钮，在扩展中粘贴配对码。配对码 3 分钟有效且仅使用一次；不要发给其他人。

02 / 日常使用

登录 → 读取 → 确认

  1. 在安装扩展的同一 Edge 配置文件中登录美团。
  2. 先暂停自动调度并关闭登录助手，在同一普通浏览器窗口打开美团评价管理，待列表加载后点击扩展“读取并核对”。
  3. 核对酒店名称和门店 ID，确认各后台属于同一账号后保存。

推广、亮点或公益后台未建立会话时，先正常打开相应页面再读取。额外后台仅标记“已读取”，不代表已验证。

你始终掌握授权

配对授权保存在本机，30 天到期。撤销后扩展不能继续导入；已保存的登录配置保持不变。重置本地配置也会撤销授权。
